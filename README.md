# 合格ラインのつまみ（gokaku-line）

架空の A組・B組の点数の柱（一人ひとりに「実は力あり／なし」の印）で、組ごとに合格ラインのつまみを動かし、3つの公平メーター（合格率・見逃し率・当たり率）をそろえる1日5問のゲーム。3つ全部は、力ありの割合が2組でちがうと、どう動かしてもそろわない。

遊ぶ: <https://satou-aaaaa.github.io/gokaku-line/>

- 3つのメーターと「同時にはそろわない」ことは、次の論文の考え方をやさしくしたもの（定義そのものではない）。Kleinberg・Mullainathan・Raghavan "Inherent Trade-Offs in the Fair Determination of Risk Scores"（2016） <https://arxiv.org/abs/1609.05807> 、Chouldechova "Fair prediction with disparate impact"（2017） <https://arxiv.org/abs/1703.00056> 、Hardt・Price・Srebro "Equality of Opportunity in Supervised Learning"（2016） <https://arxiv.org/abs/1610.02413> 。
- 答えは、線の組を全部（81通り）調べて決めている。
- 点数・組・人はすべて架空です。実在の試験や人の集まりとは関係ありません。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
